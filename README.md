# BeamNG RP Коннект и Мультиплеер

Это проект для интеграции Telegram Mini App (TMA) с игрой BeamNG.drive. Система поддерживает мультиплеер через локальную сеть (например, Radmin VPN).

## 🚀 Быстрый старт для ХОСТА (того, кто держит сервер)

1. **Сервер**:
   - Установите Node.js.
   - Запустите сервер: `node relay-server.cjs`.
   - Убедитесь, что порт `3000` открыт или вы используете Radmin VPN.

2. **Telegram Бот**:
   - Настройте ваш Telegram Bot и укажите URL вашего `index.html` (или захостите на GitHub Pages).
   - В приложении (TMA) нажмите на иконку шестеренки (Settings) и укажите `localhost` (если играете сами) или ваш Radmin IP.

3. **BeamNG.drive**:
   - Положите `integration_mod.lua` в папку модов игры.
   - В игре откроется консоль (~) или проверьте логи: должно быть написано `МОД ЗАГРУЖЕН`.

## 🤝 Инструкция для ДРУГА (клиента)

1. **Radmin VPN**:
   - Подключитесь к сети хоста. Скопируйте IP-адрес хоста.

2. **Приложение**:
   - Откройте TMA.
   - Нажмите на иконку шестеренки и введите IP-адрес хоста.

3. **Мод в игре**:
   - В папке с модом появится файл `integration_mod_config.json` после первого запуска.
   - Измените его:
     ```json
     {
         "serverIP": "IP_ХОСТА_ИЗ_RADMIN",
         "username": "Ваш_Ник"
     }
     ```
   - Перезагрузите Lua в игре (Ctrl+L).

## 🎮 Настройка BeamMP Сервера (для игры с друзьями)

Если вы хотите играть вместе через BeamMP:

1.  **Хост (Сервер)**:
    - Скачайте `BeamMP-Server.exe` с [официального сайта](https://beammp.com/).
    - Создайте папку для сервера и запустите файл один раз.
    - В `ServerConfig.toml` вставьте свой **AuthKey** с сайта [Keymaster](https://keymaster.beammp.com/).
    - Убедитесь, что вы и друзья в одной сети **Radmin VPN**.

2.  **Как подключаться**:
    - Друг заходит через **BeamMP Launcher**.
    - В разделе **Direct Connect** вводит ваш IP из Radmin VPN и порт `30814`.

3.  **Куда кидать МОДЫ**:
    - Чтобы моды работали у всех, кладите их в папку сервера: `Resources/Client/`.
    - Файлы должны быть в формате `.zip`. Распаковывать их не нужно.
    - Игра сама скачает их другу при подключении.

### 🤖 Мультиплеерный Бот (для спавна)

Чтобы бот работал у обоих:
1.  **Хост**: В игре (`integration_mod_config.json`) укажите `username: "Ivan"`. В приложении (TMA) также выберите этот ник (Settings -> Name) и IP `localhost`.
2.  **Друг**: В игре укажите `username: "Sergei"`. В приложении — тот же ник и ваш IP из Radmin VPN.
3.  **Важно**: Ники в игре и в боте должны **строго совпадать**. Это не обязательно ник из BeamMP, просто любой одинаковый текст для связки.

## 🛠 Особенности
- **Оплата по километрам**: 1 км = $200.
- **Авто-спавн**: Машина появляется сразу после нажатия «Начать смену».
- **Мультиплеер**: Сервер разделяет деньги и прогресс для каждого игрока по его имени.

## 📦 Деплой на GitHub

2. Загрузите все файлы (кроме `node_modules`).
3. Включите **GitHub Pages** для `index.html`, чтобы бот мог открывать приложение по ссылке.
